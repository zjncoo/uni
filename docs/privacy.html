Informativa Legale & Privacy

Privacy Policy & Cookie Policy

Ultimo aggiornamento: 13 Settembre 2026

1. Titolare del Trattamento

Il presente documento descrive le modalità di gestione del sito web https://zjncoo.github.io/uni/ e dell'applicazione software per macOS denominata uni con riferimento al trattamento dei dati personali degli utenti ai sensi del Regolamento Generale sulla Protezione dei Dati dell'Unione Europea (GDPR - Regolamento UE 2016/679) e della normativa italiana in vigore.

Il Titolare del trattamento è Francesco Zanchetta (zinco.cc), contattabile tramite la repository ufficiale su GitHub (zjncoo/uni) o via email all'indirizzo associato al dominio zinco.cc.

2. Privacy nell'Applicazione macOS "uni"

Privacy al 100% Locale & Offline-First

L'applicazione uni non raccoglie, non memorizza e non trasmette alcun dato personale su server remoti né a terze parti.

  • Nessun Account né Registrazione: Non è richiesto creare un profilo, effettuare login o fornire credenziali personali per utilizzare l'app.
  • Dati Accademici Locali: Corsi, orari di lezione, appelli d'esame, voti registrati, scadenze e note rimangono archiviati esclusivamente sul disco rigido locale del tuo Mac.
  • Gestione File Zero-Copy: Le slide, dispense e file PDF collegati alle materie rimangono nelle cartelle del Finder scelte dall'utente. uni conserva solo un puntatore locale (security-scoped bookmark) senza duplicare i file né caricarli sul cloud.
  • Sincronizzazione Calendario (iCal): La lettura di feed iCal/webcal universitari avviene tramite connessione diretta e crittografata tra il Mac e l'indirizzo dell'ateneo specificato dall'utente, senza passare attraverso intermediari.
  • Integrazione Microsoft Outlook: L'interazione con la casella postale di Outlook per Mac avviene esclusivamente in locale tramite il framework AppleScript nativo di macOS. L'app non accede a password né invia comunicazioni a server esterni.
  • Nessuna Telemetria né Tracciamento: uni non include SDK pubblicitari, librerie di analytics o telemetria di utilizzo.

3. Trattamento Dati sul Sito Web

Il sito web https://zjncoo.github.io/uni/ è un sito statico informativo ospitato sull'infrastruttura di GitHub Pages fornita da GitHub Inc. (Microsoft Corporation).

Durante la navigazione, i server di GitHub possono registrare automaticamente alcuni dati tecnici di accesso (indirizzo IP di provenienza, data e ora della richiesta, User-Agent del browser, pagine richieste) strettamente necessari per garantire la sicurezza del servizio, prevenire attacchi informatici e manutenere l'infrastruttura. Tali log sono gestiti in conformità alla GitHub General Privacy Statement.

4. Cookie Policy

Questa sezione descrive l'utilizzo di cookie e tecnologie affini sul nostro sito web in conformità al Provvedimento del Garante per la protezione dei dati personali e alla Direttiva ePrivacy 2002/58/CE.

Zero Cookie di Profilazione o Tracciamento Pubblicitario

Questo sito NON utilizza cookie di profilazione, NON utilizza pixel pubblicitari (come Meta Pixel o Google Ads) e NON vende dati a soggetti terzi.

Tipologie di Strumenti Utilizzati:

Strumento Tipologia Finalità Durata
localStorage: uni_site_lang Tecnico Locale Memorizza la preferenza della lingua (Italiano o Inglese) selezionata manualmente dall'utente per offrire la corretta versione linguistica nelle visite successive. Persistente (fino a pulizia dati browser)
Google Fonts Servizio Esterno Fornitura tipografica (Inter & JetBrains Mono) da CDN Google. Non installa cookie di profilazione sul dispositivo. Sessione di navigazione
GitHub Releases API Servizio Esterno Chiamata HTTP client-side anonima verso api.github.com per verificare l'ultima versione disponibile dell'applicazione (.dmg e .zip). Temporanea / Nessun cookie

Poiché il sito fa esclusivo impiego di strumenti tecnici necessari per il funzionamento e non utilizza cookie di profilazione o analitici di terze parti a fini di tracciamento incrociato, ai sensi della normativa vigente non è richiesta l'esposizione del banner di consenso preventivo per i cookie.

Come Gestire o Disabilitare lo Storage del Browser

Puoi cancellare in qualsiasi momento la cronologia e i dati locali del sito (compreso il localStorage) direttamente dalle impostazioni del tuo browser:

  • Safari: Impostazioni → Privacy → Gestisci dati siti web → Rimuovi.
  • Chrome: Impostazioni → Privacy e sicurezza → Dati dei siti web.
  • Firefox: Opzioni → Privacy e sicurezza → Cookie e dati dei siti web.

5. Diritti dell'Utente (GDPR)

In conformità agli articoli 15-22 del Regolamento UE 2016/679, ciascun utente ha il diritto di:

  • Accedere ai propri dati personali eventualmente trattati e richiederne copia;
  • Chiedere la rettifica di dati inesatti o l'integrazione di quelli incompleti;
  • Chiedere la cancellazione dei dati («diritto all'oblio»);
  • Ottenere la limitazione del trattamento o opporsi allo stesso per motivi legittimi;
  • Proporre reclamo all'Autorità di controllo competente (per l'Italia, il Garante per la Protezione dei Dati Personali).

Si ricorda che, non conservando uni alcun dato personale su propri server, l'esercizio della maggior parte dei diritti (es. cancellazione dei dati accademici) si effettua in totale autonomia eliminando l'applicazione dal proprio Mac o cancellando la memoria locale del browser.
